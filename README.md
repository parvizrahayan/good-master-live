# good-master-live v1

صفحهٔ کارگاه زنده: گره‌ها، شبیه‌سازها، دستیار، و پخش زندهٔ مجری به مخاطبان.

- index.html : خود صفحه (مخاطب: `/?room=main` ، مجری: `/?host=1&room=main`)
- config.js : نشانی رله و دستیار (بعد از استقرار Worker پر شود)
- relay/ : Worker (رله و دستیار)

بدون پر کردن config.js صفحه مستقل کار می‌کند ولی پخش زنده و دستیار هوشمند ندارد.
